# Frontend – Note anonime (React SPA)

Aplicație Single Page Application realizată în React (Vite), care consumă un backend REST (Node.js + Express).

## Rulare locală

### Cerințe
- Node.js (v18+ recomandat)
- Backend-ul trebuie să ruleze pe `http://localhost:3000`

### Pași
```bash
cd frontend
npm install
npm run dev

### Aplicația va fi disponibilă la:
http://localhost:5173
